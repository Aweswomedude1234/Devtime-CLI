DevTime CLI
A CLI for developers tracking and managing their work time.

Install
On MacOS, run:
curl -fsSL https://raw.githubusercontent.com/Aweswomedude1234/Devtime-CLI/main/install.sh | sh

Then open a new terminal and run:
devtime

What DevTime can do:
 - work and break timers
 - custom work/break intervals
 - Premade session strategies
 - Session history
 - Git activity Tracking
 - Session Planning

Commands
Once inside DevTime, type /help to see all the available commands. to exit use /quit. 

As of now this is only for MacOS. Windows coming soon. Future developments include better visuals and notifications.
